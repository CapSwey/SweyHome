# 🏠 SweyHome

My personal browser startpage, hosted via GitHub Pages.

## ✨ Features

* **Fast & Lightweight:** Built with pure HTML and CSS without heavy frameworks.
* **Custom Branding:** Features a personal logo (`capswey.png`) and custom favicons (`sweyficon`).
* **Self-Contained:** Uses local webfonts (`webfonts/`) for fast loading times.
* **Responsive:** Works smoothly across both desktop and mobile browsers.
