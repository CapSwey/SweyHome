# 🏠 SweyHome

My own personal, fast, and clean browser startpage, hosted privately via **GitHub Pages**.

## ✨ About This Project

SweyHome is built strictly for personal use to provide instant access to my favorite websites, daily tools, and bookmarks without distractions, trackers, or ads.

* **Fast & Lightweight:** Built with pure HTML and CSS without heavy frameworks.
* **Custom Branding:** Features a personal logo (`capswey.png`) and custom favicons (`sweyficon`).
* **Self-Contained:** Uses local webfonts (`webfonts/`) for fast loading times and offline resilience.
* **Responsive Design:** Works smoothly across both desktop and mobile browsers.

## 📂 Project Structure

```text
SweyHome/
├── index.html      # Main page structure and bookmarks
├── capswey.png     # Personal logo / avatar
├── assets/         # Visual assets and icons
├── css/            # Stylesheets and layout rules
├── images/         # Background or page images
├── sweyficon/      # Custom favicon files
└── webfonts/       # Locally hosted fonts
```

## 🛠️ Updating & Local Testing

To add new links or tweak the layout:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Edit `index.html`** (or the files in `css/`) using your preferred code editor.
3. **Preview locally** by opening `index.html` directly in your browser.
4. **Push to `main`:** Pushing changes to GitHub automatically updates the hosted page.
